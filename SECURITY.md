# Security Policy

This SDK runs inside our publishers' apps, so a vulnerability here is theirs too.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository
(https://github.com/admoai/admoai-flutter/security/advisories/new).

We acknowledge reports within two business days and keep you updated until a fix is
released. Fixes ship as a patch release; the advisory is published once integrators
have had a release to upgrade to.

## Supported versions

Only the latest minor release receives security fixes. Upgrade to the newest version
before reporting, if you can.
